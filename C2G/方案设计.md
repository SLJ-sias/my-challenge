## 2. 技术选型（每一项的「为什么」）

### 2.1 Tokenizer：**SentencePiece BPE 8192**（替换 BPE 1024）

**为什么：**
- 历史 top 5 提交**全部**用 SP8192
- SP 训练时 unigram + BPE 混合切分，对字节级 BPB 友好
- 8192 vocab vs 1024 vocab：每 token 编码更多字节，相同模型容量下 BPB 显著下降

**参数：**
- character_coverage = 0.9995
- model_type = "bpe"
- byte_fallback = True（覆盖所有 256 字节）
- split_by_unicode_script = True
- max_sentence_length = 8192

**文件：** `bpe_8192.model`（~2 MB）+ `bpe_8192.vocab`

### 2.2 优化器：**Muon（隐藏层）+ AdamW（embedding/output head）**

**为什么：**
- Muon 对 2D 权重矩阵做 Newton-Schulz 正交化，比 AdamW 训练快 35%（Keller Jordan 数据）
- 但 embedding 是 1D-lookup-like 结构，Muon 不适用 → 混合策略

**Muon 参数（来自 modded-nanoGPT）：**
```python
newton_schulz_coeffs = (3.4445, -4.7750, 2.0315)
ns_steps = 5
momentum = 0.95
weight_decay = 0.0  # Muon 不需要 WD
lr = 0.02  # 比 AdamW 高 10 倍
```

**AdamW 参数（embedding + 1D 参数）：**
```python
lr = 2e-3
betas = (0.9, 0.95)
eps = 1e-8
weight_decay = 0.1
```

### 2.3 架构：**9L × 512D，Tied Embedding，GQA 4 KV head**

**为什么：**
- 与 baseline 一致（最小化与历史对比的混淆变量）
- Tied embedding 减少 ~2 MB 参数空间
- GQA（4 KV head）相比 MHA 省 ~30% KV cache

**QK-gain trick：** 在 Q/K projection 后乘 `1 / sqrt(head_dim)` 的稳定项（modded-nanoGPT 经验值 = 5.0），减少 attn logit 爆炸。

### 2.4 量化：**int8 embedding + bf16 主干**

**为什么：**
- 主干权重 bf16（精度优先）
- embedding 用 int8 + per-channel scale（参数量最大、单独量化无损）
- 16 MB 预算下：embedding 从 ~4 MB → ~1 MB，省 3 MB 给主干

**预期代价：** BPB 升 0.001–0.003，可接受

### 2.5 训练循环：**torch.compile + FlashAttention 3 + bf16**

**为什么：**
- torch.compile 在 H100 上对 Transformer 提速 15–25%
- FlashAttention 3 是 H100 native 实现
- bf16 而非 fp16：动态范围更大，loss 不易 NaN

## 4. 测量协议（方法学核心）

### 4.1 三个独立原则

**原则 1：单变量原则** —— 每次只改 1 个，其他保持 baseline 配置。从 E000→E001→E003 的差值才有意义。

**原则 2：3 seed 取 ±stderr** —— 1 次跑得 BPB=1.18 不能说明问题；3 次跑均值 1.18 ± 0.003 才能。

**原则 3：预登记论证** —— 实验前在 `logs/hypothesis.md` 写下「我假设 X 改进 Y，因为 Z」；实验后填实际值。如实际值与假设差 > 0.01，触发深度复盘。

### 4.2 显著性检验

- **目标 SOTA：** BPB 改善 ≥ 0.005 nats（官方榜单要求）
- **统计显著性：** p < 0.01（Welch t-test，对照 baseline vs 改进组）
- **样本量：** n=3 each（最小可发表标准）

### 4.3 数据记录

每次跑保存以下文件：
- `logs/{exp_id}_{seed}.json`：训练指标
- `logs/{exp_id}_{seed}.csv`：每 100 step 的 loss/grad_norm/tokens_per_sec
- `logs/{exp_id}_eval.json`：BPB 评估结果
- `logs/{exp_id}_config.yaml`：完整超参
