# C4 教学说明：aar-generator 上手指南

> 目标读者：拿到 `86181_C4_aar-generator.skill` 的同学。读完本文，10 分钟内跑出你的第一份 AAR。

| 你是 | 上手路径 | 耗时 |

| A. 用 Claude/Cursor 等 AI 客户端 | 安装 .skill → 说一句话 | 2 分钟 |

## 二、路径 A：AI 客户端用户（推荐）

**第 1 步 · 安装**：把 `.skill` 文件导入你的技能库（各客户端入口不同：Claude 技能目录 / WorkBuddy 技能中心 / Cursor rules 目录，本质都是解压后让 SKILL.md 被加载）。

**第 2 步 · 触发**：用任何一句自然语言：

> "帮我复盘这个挑战：D:/挑战任务成果/C5"

或英文 "Generate an AAR for /path/to/folder"，或口语化 "马上交 C4 了，帮我检查还缺什么交付物"。

**第 3 步 · 检查输出**：AI 应该先跑脚本、给你看数据骨架，再写叙述。如果它**没跑脚本直接开写**，说明触发失败，补一句："请先运行 scripts/aar_extractor.py 再写复盘"。

**第 4 步 · 收文件**：确认拿到两样——`AAR骨架_*.md`（数据）+ `AAR.md`（完整复盘）。骨架别删，它是复盘数字的证据链。

## 三、路径 B：命令行用户

```bash
# 任何 Python ≥ 3.8，无需安装任何第三方包
python aar_extractor.py "你的挑战成果文件夹" --challenge C2G --out ./output --json
```

参数速查：

| 参数 | 作用 | 缺省行为 |
|---|---|---|
| `folder`（必填） | 挑战成果文件夹 | — |
| `--challenge` | 指定挑战 ID（如 C4） | 从文件夹名/README 自动猜 |
| `--out` | 输出目录 | 打印到终端 |
| `--json` | 同时输出机器可读 JSON | 只出 Markdown |

## 四、常见坑（实测踩过/预判的）

| 坑 | 症状 | 解法 |
|---|---|---|
| ① 路径没加引号 | 中文/空格路径解析错误 | 命令里路径永远加双引号 |
| ② Git Bash 下用 tar 处理 `D:` 路径 | `Cannot connect to D: resolve failed` | tar 的老毛病；本技能脚本无此问题，直接用 python 跑 |
| ③ 文件夹里全是截图/视频 | 字数/行数显示 `—` | 正常：脚本只统计文本文件，二进制只进清单 |
| ④ 缺口报告误报 | 你的文件名和注册表模式不符 | 改 `references/deliverables.json` 追加你的命名模式，无需动代码 |
| ⑤ AI 没跑脚本直接写作文 | 复盘全是形容词没数字 | 明确指令："先运行脚本，把骨架数据贴给我看" |
| ⑥ 无 AI 日志 | 轮次信号 0 | 如实标注即可（本身是 red flag，评分会扣）——先补日志再复盘 |

## 五、优化技巧（进阶）

1. **每个挑战当天跑一次**：时间线靠文件 mtime 重建，越早跑越准；拖到月底，中间版本会丢失。
2. **让 AI 只补"为什么"和"下次怎么办"**：数据部分锁定骨架，人工核对后让 AI 写 3、4 两问——这是人最有判断力、AI 最容易空话的部分。
3. **把你的挑战加进注册表**：新挑战只要在 `deliverables.json` 加一行模式数组，缺口检查立即覆盖。
4. **JSON 别扔**：`--json` 输出可以直接喂给后续统计（比如跨挑战的工作量对比图）。

## 六、纯手动版（不装任何东西）

即使不用本技能，也可以照它的思路手动做复盘，顺序是：

1. 列产物清单（文件名/大小/日期）
2. 按修改时间排时间线 → 找出活跃日和空档
3. 数 AI 对话轮次，标出打回重做的轮
4. 对照挑战要求列 ✅/❌ 缺口
5. 按"四问"写叙述：计划 / 事实 / 根因（主观 vs 客观）/ 下次（≤3 条带优先级）

**每条结论必须挂一个数字**——这一条做到，你的复盘就超过 80% 的敷衍版。
