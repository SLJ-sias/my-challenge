# C4 技能说明：aar-generator（数据驱动的挑战复盘生成器）

> **作者：** 86181 · **挑战：** C4 技能分享与传播 · **日期：** 2026-10-11
> **技能包：** `86181_C4_aar-generator.skill`（ZIP 格式，与官方示例一致，可直接安装）

---

## 一、一句话 I/O

**输入**一个挑战成果文件夹路径，**输出**一份数据驱动的 AAR 复盘骨架（产物清单 / 工作时间线 / 迭代轮次 / AI 工具统计 / 交付物缺口），再由 AI 按四问模板补全叙述，得到最终 `AAR.md`。

---

## 二、解决什么问题

Elite20 每个挑战都要交 **AI 日志 + AAR 复盘**，这是全员、每挑战、必交的高频需求，但存在三个痛点：

| 痛点 | 现状 | 本技能的解法 |
|---|---|---|
| 复盘没数据 | "效果很好""学到很多"，评分人无从采信 | 脚本自动统计文件数/字数/活跃天数/轮次信号，结论必须挂数字 |
| 交付前漏盘点 | 交完才发现缺 AAR、缺 demo | 对照 `deliverables.json` 注册表自动缺口检查，❌/✅ 一目了然 |
| 翻旧账成本高 | 几十个文件跨多天，人工重建迭代史费时 | 按文件修改时间自动重建逐日工作时间线 |

**技能四条件自检：**

| 条件 | 检验 |
|---|---|
| 可复用 | 纯 Python 标准库（3.8+），Windows/macOS/Linux 通用；不依赖作者环境 |
| 可执行 | `aar_extractor.py` 可直接运行；SKILL.md 含完整 5 步工作流 |
| 可验证 | 给定输入文件夹，输出确定：文件数、字数、缺口项均可复核（见 demo） |
| IO 明确 | 输入=文件夹路径，输出=AAR骨架_*.md（+可选 JSON / 规范化 AI日志） |

## 三、技能架构

```
aar-generator/
├── SKILL.md                      （主指令，~180 行）
│   ├── YAML frontmatter          → name + description（13 个中英触发短语）
│   ├── 五步工作流                → 跑脚本 → 读数据 → 写叙述 → 出文件 → 自检
│   └── 边界情况                  → 空文件夹/无日志/截图日志/中文路径/未知挑战 等 9 种
├── scripts/
│   └── aar_extractor.py          （14.8 KB 确定性引擎：扫描+时间线+轮次统计+缺口检查）
└── references/
    ├── aar-template.md           （AAR 四问模板、7 节结构、写作红线、AI日志规范格式）
    └── deliverables.json         （C1–C10H 挑战交付物注册表，追加条目即扩展）
```

**三层加载机制**：frontmatter（常驻，决定触发）→ SKILL.md 正文（触发时加载）→ references（按需加载）。脚本不需要"被理解"，直接执行。

## 四、核心设计（拿了/改了/为什么）

| 设计 | 拿了什么 | 改了什么 | 为什么 |
|---|---|---|---|
| 结构 | 官方示例 wechat-doc-mapper 的 scripts + references 双层结构 | 保留；注册表由 YAML 改为 JSON | 零依赖（不装 PyYAML），陌生人复制即跑 |
| 缺口检查 | wechat-doc-mapper 的"预期产物对照"思路 | 匹配模式对齐真实命名（如 `glossary*` 而非 `*术语表*`） | 用 C1 真实成果回归测试校准 |
| 轮次统计 | 无现成方案 | 自创 4 组正则信号（`## N`、`第N轮`、`Round N`、`第N版`） | AI 日志格式五花八门，多信号取最大值更鲁棒 |
| 编码 | 无 | utf-8 → gb18030 → latin-1 三级回退读取 | Windows 中文文件名的 GBK 文件不炸 |
| 时间线 | 无 | 按天聚合文件 mtime，含周几与空档日 | 复盘"实际发生了什么"最需要节奏事实 |

## 五、使用步骤

1. **安装**：解压/安装 `86181_C4_aar-generator.skill` 到技能目录。
2. **触发**（任一说一句）：
   - "帮我复盘这个挑战：D:/挑战任务成果/C2G"
   - "检查我的 C4 交付物缺口"
   - "generate an AAR for this folder"
3. **得到**：`AAR骨架_<ID>.md`（数据）→ AI 补全四问叙述 → 最终 `AAR.md`。
4. **直接用脚本**（不经 AI 也行）：
   ```bash
   python aar_extractor.py "D:/挑战任务成果/C2G" --challenge C2G --out ./out --json
   ```
